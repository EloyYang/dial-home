# 다이얼 홈 (Dial Home)

투명한 다이얼을 눌러 돌리면 앱이 실행되는, 비어 있는 홈 화면 런처입니다.

## 설치
[Releases](../../releases/latest)에서 최신 `DialHome.apk`를 내려받아 설치합니다.
한 번 설치하면 이후 버전은 앱이 이 저장소의 최신 릴리스를 확인해 스스로 업데이트합니다.

## 주요 기능
- 원하는 위치에 놓는 투명 다이얼: 누르고 8방향으로 끌어 앱 실행
- 위젯 자유 배치 / 칸 맞춤, 위젯 스택
- 위로 쓸어올려 앱·설정 검색, 즐겨찾기, 별명
- 여러 홈 화면
